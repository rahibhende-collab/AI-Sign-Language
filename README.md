# 🤟 Sanket – AI-Powered Sign Language Platform

**Sanket** is an ongoing AI-powered Indian Sign Language (ISL) communication and learning platform designed to bridge the communication gap between sign language users and non-sign-language users.

The platform uses **SARA (Sign Language AI Recognition Assistant)** as its AI model to recognize and interpret Indian Sign Language and convert signs into meaningful text and, where applicable, speech.

> 🚧 **Project Status: Ongoing / Under Development**
> The project is currently under development. The folder structure, complete AI model integration, and several features are yet to be finalized.

## 🎯 Objectives

* 🤟 Recognize Indian Sign Language gestures.
* 📝 Convert signs into understandable text.
* 🔊 Provide text-to-speech functionality.
* 📚 Support ISL learning and practice.
* 🤖 Integrate the **SARA AI model** for sign recognition.
* 🌍 Make communication more accessible and inclusive.

## 🧠 AI Model – SARA ##

**SARA (Sign Language AI Recognition Assistant)** is the planned AI model for Vachetram.

SARA will be responsible for analyzing sign language inputs and identifying corresponding signs, words, or phrases.

The AI implementation is currently under development and may be integrated using suitable AI/ML models and APIs.

## 🔐 API Keys

The project may require API keys for AI services and other external APIs.

API keys will **not be stored directly in the source code**. They will be managed using environment variables:

```env
AI_API_KEY=your_api_key_here
```

The `.env` file will be added to `.gitignore` to prevent sensitive credentials from being uploaded to GitHub.
